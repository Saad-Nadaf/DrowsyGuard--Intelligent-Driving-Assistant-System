# 🚗 Intelligent Driving Assistant System (IDAS)

A smart driving assistant mobile application built using Expo that enhances road safety by monitoring driving conditions and providing real-time alerts to the driver.

---

## 🚀 Features

- 🚘 Driver assistance system  
- ⚠️ Real-time alerts for unsafe conditions  
- 📱 Mobile-based interface (Expo app)  
- 🔍 Monitoring of driving situations (basic logic)  
- 🛡️ Focus on road safety and awareness  

---

## 🛠️ Tech Stack

- React Native (Expo)
- JavaScript
- Expo Router (file-based routing)
- Mobile UI Components

---

## 📂 Project Structure
IDAS/
│── app/ # Main application screens
│── assets/ # Images, icons, etc.
│── components/ # Reusable UI components
│── package.json # Dependencies

---

## ⚙️ Getting Started

### 1. Install Dependencies
```bash
npm install
2. Run the App
npx expo start
```bash
